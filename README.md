This is the repository related to the paper:

Where is What? A Comprehensive Layer-wise Analysis of Content, Speaker, and Prosody in Speech SSL Models

To run the model, please download models 

model_configs = {
    "WavLM-Base+": "wavlm-base-plus",
    "HuBERT-Base": "hubert-base",
    "Wav2Vec2-Base": "wav2vec2-base",
    "Data2Vec-Audio": "data2vec-audio-base-960h",
    "Whisper-Small (Enc)": "whisper-small"
and save into MODELS_DIR = "./pretrained_models" folder.

Then Run from Scripts From number 1 to 4
